# USTtoMShelper

面向音 MAD / YTPMV 制作的 After Effects 脚本，根据 UST / USTX 歌词与音符时间生成日语元音口型动画。

## 当前版本

**v0.8.0**

本版本改进 USTX 轨道选择显示、促音识别与连续同元音处理。

## 已实现功能

- 创建用户指定宽度和高度的样板合成与五段口型动画添加时间标记。
- 读取传统 `.ust` 文件，可选择自动、UTF-8 或 Shift-JIS 编码。
- 导出 TSV 音符事件表，查看音符、时间、歌词与元音识别结果。
- 对时间轴中选中的样板合成图层生成 Time Remapping 关键帧。

### 默认时间标记

| 标记 | 时间 | 含义 |
|---|---:|---|
| `a` | 0.0 s | a 动画开始 |
| `a-hold` | 0.5 s | a 长音维持位置 |
| `i` | 1.0 s | i 动画开始 |
| `i-hold` | 1.5 s | i 长音维持位置 |
| `u` | 2.0 s | u 动画开始 |
| `u-hold` | 2.5 s | u 长音维持位置 |
| `e` | 3.0 s | e 动画开始 |
| `e-hold` | 3.5 s | e 长音维持位置 |
| `o` | 4.0 s | o 动画开始 |
| `o-hold` | 4.5 s | o 长音维持位置 |
| `o-end` | 5.0 s | o 动画结束 |
| `closed` | 5.5 s | 闭口状态 |

## 使用方法

1. 下载并在 After Effects 中安装 `USTtoMShelper.jsx`。
2. 根据自身要求创建样板合成，在样板合成中置入口型动画。
3. 导入 UST 文件，退回到上一级合成并选中样板合成，生成时间重映射。

## 注意事项
- 当前仅处理传统 `.ust` 文件，不处理 `.ustx`。
- 当前只按日语元音分类，不分析辅音，也不支持其他语言的完整发音规则。
- 部分歌词别名无法自动识别，会标记为 `unknown`；应用时暂按闭口处理。
- 应用前必须激活外层合成，并且选中一个引用样板合成的图层。
