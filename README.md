# USTtoMShelper

面向音 MAD / YTPMV 制作的 After Effects 脚本，根据 UST / USTX 歌词与音符时间生成日语元音口型动画。

## 当前版本

**v0.9.0**

修复连续同元音处理的问题。

## 已实现功能

- 创建用户指定宽度和高度的样板合成与五段口型动画添加时间标记。
- 读取 `.ust` 文件，可选择自动、UTF-8 或 Shift-JIS 编码。
- 读取 UTF-8 编码的 `.ustx` 文件，并解析轨道、歌手、声部、歌词、音符位置、音符时长与 Tempo 变化。
- 将同一 USTX 轨道中的多个声部合并到一条时间线上；音符之间的空隙按闭口处理。
- 导出 TSV 音符事件表，查看音符、时间、歌词与元音识别结果。
- 对时间轴中选中的样板合成图层生成 Time Remapping 关键帧。
- 目标来源合成含有完整且顺序正确的口型标记时，读取来源标记；否则使用默认时间布局。

### 默认时间标记

| 标记 | 时间 | 含义 |
|---|---:|---|
| `a` | 0.0 s | a 动画开始 |
| `a-hold` | 0.5 s | a 长音维持位置 |
| `i` | 1.0 s | i 动画开始 |
| `i-hold` | 1.5 s | i 长音维持位置 |
| `u` | 2.0 s | u 动画开始 |
| `u-hold` | 2.5 s | u 长音维持位置 |
| `e` | 3.0 s | e 动画开始 |
| `e-hold` | 3.5 s | e 长音维持位置 |
| `o` | 4.0 s | o 动画开始 |
| `o-hold` | 4.5 s | o 长音维持位置 |
| `o-end` | 5.0 s | o 动画结束 |
| `closed` | 5.5 s | 闭口状态 |

## 使用方法

1. 下载并在 After Effects 中安装 `USTtoMShelper.jsx`。
2. 在生成的样板合成中填入口型动画。
3. 切换到“口型生成”，导入 `.ust` 或 `.ustx` 文件。
4. 对于 `.ust` 文件，请选择编码格式；对于 `.ustx` 文件，请选择轨道。
5. 退回到上一级合成并选中填充后的样板合成，点击“应用到视频/合成”，生成时间重映射关键帧。

## USTX 解析说明

- USTX 按 UTF-8 读取，不显示传统 UST 的编码选项。
- 轨道信息从 `tracks` 读取；音符从 `voice_parts` 中读取，并根据 `track_no` 归属到相应轨道。
- 同一轨道的多个声部会按时间合并；声部起始位置、音符本地位置与时长均按 tick 计算。
- Tempo 变化从 `tempos` 读取。默认按每四分音符 480 tick 计算时间。
- 轨道下拉栏列出文件中的轨道，歌手信息缺失时显示“未指定歌手”。默认选择第一条含有音符的轨道。
- TSV 导出包含所有轨道；“应用到视频/合成”仅处理当前选择的轨道。
- USTX 是 YAML 格式。本脚本针对 OpenUtau 常见的区块式字段和简单行内映射实现解析，不是通用 YAML 解析器；使用非典型序列化方式的文件仍需实际测试。

## 口型与时间重映射规则

- 普通音符映射到其元音；拗音映射到最后一个元音；促音若能继承前一个有效元音，则归入该元；无元音、休止或未识别歌词映射到闭口标记音。
- 普通元音音符会在对应 `*-hold` 标记维持口型，再按音符结束位置过渡到下一段。
- 当音符后接无辅音音符时，为前一音符的源时间出点缩短到对应元音段起点 +0.75 秒。
- 相邻音符若时间连续且元音相同，应用时会将它们作为一段连续元音处理，不会插入新的出入点。
- 音符内部使用线性插值；音符结束出点使用保持插值，避免 AE 在相邻源时间之间穿过其他元音段。
- 短音符可能无法完整呈现全部口型变化。
- 若来源为包含完整标记的预合成，将优先读取其标记时间；否则使用默认时间布局。

## 注意事项

* 当前仅按日语元音分类，不分析辅音，也不支持其他语言的完整发音规则。
* 部分歌词别名无法自动识别，会标记为 `unknown`；应用时暂按闭口处理。
* 应用时需在时间轴中只选中一个可进行时间重映射的视频素材图层或合成图层。
* 如果外层合成时长不足以容纳所选轨道的音符时间，需先延长合成。
* 如果所选图层已启用时间重映射，确认后将替换原有时间重映射关键帧。
* 没有完整口型标记的来源不会被拒绝，但脚本会按默认时间位置取样。
